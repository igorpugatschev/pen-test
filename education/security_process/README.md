# Security QA Process Templates

Этот каталог содержит шаблоны процессных артефактов для курса `Pen-Test Learning Program`.

Шаблоны нужны, чтобы студент развивался не только как пользователь инструментов, но и как SDET, который отвечает за безопасность продукта:

- планирует scope;
- согласует ограничения;
- собирает sanitized evidence;
- оформляет findings;
- ведет remediation backlog;
- проверяет исправления;
- автоматизирует повторяемые безопасные проверки.

Рекомендуемый порядок заполнения:

1. `RULES_OF_ENGAGEMENT.md`
2. `SECURITY_TEST_STRATEGY.md`
3. `SECURITY_TEST_PLAN.md`
4. `THREAT_MODEL.md`
5. `EVIDENCE_POLICY.md`
6. `TOOLING_POLICY.md`
7. `SECURITY_FINDING_TEMPLATE.md`
8. `VULNERABILITY_TRIAGE.md`
9. `REMEDIATION_BACKLOG.md`
10. `RETEST_PLAN.md`
11. `SECURITY_AUTOMATION_ARCHITECTURE.md`
12. `SECURITY_RELEASE_CHECKLIST.md`
