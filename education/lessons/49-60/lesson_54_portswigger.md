## Теория

**PortSwigger Academy** — бесплатная образовательная платформа от создателей Burp Suite. Содержит сотни лабораторных работ по веб-безопасности.

**Особенности:**
- Лаборатории запускаются в браузере
- Реалистичные уязвимые веб-приложения
- Подробная теория перед каждой лабой
- Автоматическая проверка решения

**Темы модуля "Web Security":**
- SQL Injection (SQLi)
- Cross-Site Scripting (XSS)
- Cross-Site Request Forgery (CSRF)
- Directory Traversal
- Authentication vulnerabilities
- OAuth, JWT, WebSockets

**Burp Suite** — основной инструмент для прохождения лаб:
- **Proxy** — перехват трафика
- **Repeater** — повтор запросов с изменениями
- **Intruder** — автоматизированные атаки
- **Decoder** — кодирование/декодирование

## Практическое занятие

### Лабораторные по SQL Injection

#### Лаба 1: SQLi в фильтре товаров (учебная)
1. Откройте магазин, выберите категорию товаров
2. Перехватите запрос в Burp Proxy
3. Отправьте в Repeater
4. Измените параметр `category`: `' OR 1=1--`
5. Убедитесь, что отображаются все товары

#### Лаба 2: SQLi с UNION (определение столбцов)
```sql
' ORDER BY 1--
' ORDER BY 2--
' ORDER BY 3--  (ошибка = 2 столбца)
```
Используйте UNION:
```sql
' UNION SELECT NULL,NULL--
' UNION SELECT 'a','b'--
```

#### Лаба 3: Извлечение данных пользователей
```sql
' UNION SELECT username,password FROM users--
```

### Лабораторные по XSS

#### Лаба 4: Reflected XSS (в поиске)
Введите в поиск: `<script>alert(1)</script>`
Если скрипт выполнится — уязвимость есть.

#### Лаба 5: Stored XSS (в комментариях)
Оставьте комментарий с payload: `<img src=x onerror=alert(1)>`
При загрузке страницы скрипт выполнится у всех посетителей.

#### Лаба 6: DOM-based XSS
Изучите исходный код страницы, найдите место, где пользовательский ввод попадает в DOM без фильтрации.

## Частые ошибки

1. **Неправильная настройка Burp Proxy**: В macOS часто забывают настроить доверие к CA-сертификату Burp. Без этого HTTPS-трафик не будет перехватываться (ошибка SSL).
2. **Пропуск Lab description**: В PortSwigger Academy условия лабы содержат подсказки. Новички часто сразу лезут в Repeater, не прочитав теорию.
3. **Неправильный UNION SELECT**: Забывают, что количество столбцов в UNION должно совпадать. Используйте `ORDER BY` для определения количества столбцов перед UNION.



## Вопросы на понимание

1. Почему PortSwigger Academy считается золотым стандартом для обучения веб-пентесту?
   <details><summary>Ответ</summary>Лаборатории реалистичны, есть подробная теория перед каждой лабой, и автоматическая проверка решения без необходимости искать флаги.</details>
2. В чем разница между Reflected XSS и Stored XSS с точки зрения эксплуатации?
   <details><summary>Ответ</summary>Reflected XSS требует, чтобы жертва перешла по специальной ссылке. Stored XSS сохраняется на сервере и срабатывает при посещении страницы любым пользователем.</details>
3. Зачем нужен Burp Suite Intruder при тестировании на SQL-инъекции?
   <details><summary>Ответ</summary>Intruder позволяет автоматизировать перебор (брутфорс) параметров, определение количества столбцов и типов данных через анализ ответов сервера.</details>

## Адаптация под macOS (M2, 8GB)

- Для VPN используйте **Tunnelblick** (бесплатный OpenVPN клиент для macOS): скачайте .ovpn файл и откройте через Tunnelblick
- Виртуалки: используйте только при необходимости; для Apple Silicon выбирайте ARM64-образы в **UTM**, **VMware Fusion** или **Parallels**, а тяжелые лабы выносите в cloud lab
- "На 8GB RAM выделяйте VM не более 3-4GB"
- Docker работает нативно на M2: `docker pull <image>`
- Для macOS native используйте Homebrew или официальный installer: `brew install <tool>`; для явно помеченной Kali/Linux-среды допустим `apt`.
- Если требуется Python: `pip3 install <package>`
