# Two-Layer Course Design

## Goal

Convert the penetration testing curriculum into a two-layer teaching model for beginners: a mandatory safe path and an optional deepening path.

## Design

Each lesson receives a standard "Учебная рамка" immediately after the title. The frame states entry requirements, expected outcome, safe target, mandatory beginner path, deepening option, minimal success check, reference output, and submission criteria.

The frame is generated by lesson block so it is not a generic placeholder. Linux lessons use local files and VM practice, networking lessons use isolated labs, OWASP lessons use DVWA/WebGoat/PortSwigger, tooling lessons use only lab targets, Python lessons use localhost or owned lab hosts, platform lessons use THM/HTB/PortSwigger scopes, and methodology lessons use written RoE/scope artifacts.

The lesson validator must enforce the new fields so future edits preserve the model. A few obvious teaching hazards are fixed while introducing the model: duplicated sections in the TryHackMe intro lesson and unsafe-looking private-router targets in brute-force and Nmap examples.

## Verification

Run `bash education/tools/check_lessons.sh` and confirm it checks all 77 lessons with no missing methodological fields. Review a representative lesson from each block to confirm the frame reads naturally and matches the block topic.
