• при использовании конструкции, ориентированной на наследование, экзем­
пляр KnownSample является экземпляром Sample. Он имеет пять атрибуто в:
все четыре атрибута, унаслед ованные от класса Sample, плюс один атрибут,
уникальный для подкласса KnownSample;

важных для прилож ения.
