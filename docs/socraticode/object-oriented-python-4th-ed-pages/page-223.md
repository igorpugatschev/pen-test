Теперь вернемся к некоторым примерам, которые уже рассмотрены в этой главе.
Начните с кэшированной неб-страницы, использующей свойство для кэширова­
ния полученных данных. Очевидная проблема в этом примере заключается в том,

Также обратите внимание на ZipProcessor, основанный на наследовании. Здесь

наследования.
