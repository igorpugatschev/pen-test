это набор модулей в папке. Имя пакета - это имя папки. Оста ется только со­
общить Python, что папка является пакет ом, чтобы отличить ее от других папок
в каталоге. Для этого надо поместить файл (обычно пустой) в папку _iпi t_.py.
Если вдруг забудем перемес тить файл в нужную папку, то не сможем импорти­
ровать модули из этой папки.
