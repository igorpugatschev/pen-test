специа льных усло вий нет. Мы будем работать со столбцом, имеющим опре де­

следов ательность ключей предоставляем мы сами, или берем из первой строки
файла. Это относительно распространено и избавляет от сложности в ситуациях,
когда заголовки стол бцов являются частью данных.
