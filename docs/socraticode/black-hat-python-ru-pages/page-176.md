Мы передаем обычный текст в виде байтов и сжимаем его . Затем случай-
ным образом генерируем ключ сеанса и шифруем  сжатый текст с помощью
шифра AES . Т еперь нужно вернуть ключ сеанса вместе с зашифрованным
текстом, чтобы последний можно было расшифровать на другой стороне. Для
этого мы шифруем ключ сеанса с использованием RSA-ключа, сгенериро -
ванного из содержимого файла key.pub . Вся информация, которую нужно
будет расшифровать, помещается в переменную msg_payload , кодируемую
в формате base64 и возвращаемую в виде итоговой зашифрованной строки .
Т еперь напишем функцию decrypt:
def decrypt(encrypted):
    encrypted_bytes = BytesIO(base64.decodebytes(encrypted)) 
    cipher_rsa, keysize_in_bytes = get_rsa_cipher('pri')
    encrypted_session_key = encrypted_bytes.read(keysize_in_bytes) 
    nonce = encrypted_bytes.read(16)
    tag = encrypted_bytes.read(16)
    ciphertext = encrypted_bytes.read()
    session_key = cipher_rsa.decrypt(encrypted_session_key) 
    cipher_aes = AES.new(session_key, AES.MODE_EAX, nonce)
    decrypted = cipher_aes.decrypt_and_verify(ciphertext, tag) 
    plaintext = zlib.decompress(decrypted) 
    return plaintext
Для расшифровки мы выполняем шаги из функции encrypt в обратном по-
рядке. Сначала преобразуем строку , закодированную как base64, в байты .
Затем считываем из расшифрованной байтовой строки  зашифрованный
ключ сеанса вместе с другими параметрами, которые нужно расшифровать.
Расшифровываем ключ сеанса с помощью закрытого RSA-ключа  и исполь-
зуем полученный результат в сочетании с шифром AES для расшифровки
самого сообщения . В конце распаковываем полученное в байтовую строку ,
представляющую собой обычный текст , и возвращаем ее.
