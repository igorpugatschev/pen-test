Взлом HTML-формы аутентификации методом перебора   115
1. Получаем страницу входа и принимаем все возвращенные нам cookie.
2. Извлекаем из HTML-кода все элементы формы.
3. Выбираем имя пользователя и/или пароль из своего словаря.
4. Отправляем скрипту входа HTTP POST вместе со всеми полями
HTML-формы и значениями cookie, которые мы сохранили.
5. Проверяем, удалось ли успешно войти в веб-приложение.
Средство восстановления паролей Cain & Abel, доступное только в Windows,
содержит большой словарь cain.txt. Воспользуемся им, чтобы подобрать
пароль. Этот файл можно скачать непосредственно из репозитория SecLists
на GitHub, принадлежащего Даниэлю Мисслеру:
wget https://raw.githubusercontent.com/danielmiessler/SecLists/master/Passwords/
Software/cain-and-abel.txt
Кстати, в SecLists есть много других словарей. Можете самостоятельно ис -
следовать этот репозиторий и поискать в нем то, что может пригодиться
в будущих проектах.
