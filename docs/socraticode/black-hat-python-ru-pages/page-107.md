Получение структуры каталогов веб-приложений с открытым исходным кодом   107
Функция run управляет анализом структуры каталогов, вызывая функции
в строго определенном порядке. Мы запускаем 10 потоков (определенных
в начале скрипта) , каждый из которых выполняет функцию test_remote .
После этого ждем, пока все эти потоки не завершатся (для этого предусмотрен
вызов thread.join), и прекращаем работу .
Т еперь в довершение всего можно добавить некоторую логику в блок __main__.
Подставьте вместо исходного блока следующий обновленный код:
if __name__ == '__main__':

    run() 
    with open('myanswers.txt', 'w') as f: 

Прежде чем вызвать gather_paths, используем диспетчер контекста chdir ,
чтобы перейти в нужную папку . Мы предусмотрели здесь паузу на случай,
если захочется сначала просмотреть консольный вывод . На этом этапе мы
уже собрали интересующие нас пути к файлам в локальной копии. Т еперь
выполняем основную процедуру анализа удаленного приложения  и запи-
сываем результаты в файл. Мы, скорее всего, получим множество успешных
запросов, в таком случае URL-адреса будут выводиться в консоль слишком
быстро для того, чтобы за ними можно было уследить. Этого можно избежать,
если добавить блок  для записи результатов в файл. Обратите внимание на
метод для открытия файла, играющий роль диспетчера контекста: он гаран-
тирует, что при выходе из этого блока файл будет закрыт.
