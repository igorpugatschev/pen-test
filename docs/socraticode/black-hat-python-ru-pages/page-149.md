Создание модулей
В последующих главах вы будете проделывать своими троянами скверные
вещи — например, записывать нажатия клавиш и создавать снимки экрана.
Но для начала напишем несколько простых модулей, которые можно будет
легко протестировать и развернуть. Создайте файл dirlister.py в каталоге
modules и наберите следующий код:
import os
def run(**args):
    print("[*] In dirlister module.")
    files = os.listdir(".")
    return str(files)

торый вы разрабатываете, должен предоставлять функцию run с переменным
