байтовую строку buffer, в которой будут накапливаться ответы, получен-
ные из сокета . Мы указываем по умолчанию время ожидания длиной

чтобы записывать ответные данные в buffer , пока они не закончатся или

вызывающей стороне — ею может быть как локальная, так и удаленная
система.
