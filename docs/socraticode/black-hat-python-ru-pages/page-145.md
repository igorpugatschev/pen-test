# Black Hat Python. Программирование для хакеров и пентестеров — страница 145

Источник: `Black Hat Python. Программирование для хакеров и пентестеров.pdf`

Подбор паролей на основе содержимого веб-сайта   145
Рис. 6.14. Передача запросов расширению BHP Wordlist
Когда вы сконфигурируете процесс сканирования, запустите его, открыв
адрес http://testphp.vulnweb.com/. Как только Burp пройдет по всем ссылкам на
заданном сайте, выберите все запросы в правой верхней панели на вкладке
Target (Цель), щелкните на них правой кнопкой мыши, чтобы отобразить
контекстное меню, и выберите пункт Create Wordlist (Создать словарь), как
показано на рис. 6.14.
Т еперь проверьте в своем расширении вкладку Output (Вывод). В реальных
условиях мы бы сохранили этот словарь в файл, но в целях демонстрации
отобразим его в Burp, как на рис. 6.15.
Сейчас этот вывод можно передать обратно в Burp Intruder, чтобы, собственно,
провести атаку по подбору паролей.
