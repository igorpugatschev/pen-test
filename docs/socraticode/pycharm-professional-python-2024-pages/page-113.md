Использование файла requirements.txt
Лучшая практика использования проектов Python – использовать файл с именем
requirements.txt	для перечисления зависимостей сторонних библиотек для ваше-
го проекта. Если вы начинаете свой проект с нуля, можете сгенерировать файл
requirements.txt, используя pip в своем терминале, с помощью этой команды:
pip freeze > requirements.txt
