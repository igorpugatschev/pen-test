Вы можете управлять цветами каждого окна приложения в каждом контек-
сте, в котором они используются. Например, у вас могут быть разные цветовые
схемы для файлов SQL, файлов JavaScript и файлов Python.
Возможно, самая полезная настройка в этом лоте – это возможность настро-
ить шрифт, который отображается во встроенном окне терминала PyCharm.
Вы можете видеть это на рис. 2.17.
