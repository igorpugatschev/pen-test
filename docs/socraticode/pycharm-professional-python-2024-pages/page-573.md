Рис. 15.20.	Выберите IDE, которую вы хотите использовать на удаленном компьютере
Другое, возможно, очевидное соображение заключается в том, что вам по-
требуется лицензия на любую IDE, которую вы выберете. Далее нам нужно
выбрать место. Это может сбить вас с толку, поскольку структура файловой
системы Linux отличается от структуры Windows. Linux не использует буквы
дисков и использует косую черту для разделения элементов пути, тогда как
Windows использует обратную косую черту. К  счастью, я  могу просто про-
смотреть это, кликнув три точки рядом с настройкой каталога проекта. По-
смотрите на рис. 15.21.
По умолчанию браузер каталогов отображает вашу домашнюю папку на
удаленном компьютере. Вы можете перейти к папке по вашему выбору. К со-
жалению, на данный момент отсутствует одна большая функция – возмож -
ность создать новую папку для вашего проекта. Я  уверен, ее установят, но
в денный момент ее нет. Нам придется поработать над этим. Нажмите Can-
cel,	затем Back,	чтобы вернуться к экрану, показанному на рис. 15.5. Нажми-
те кнопку терминала, чтобы запустить сеанс терминала SSH на хосте, как по-
казано на рис. 15.22.
