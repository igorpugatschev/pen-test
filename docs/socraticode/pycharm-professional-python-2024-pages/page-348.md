Рекомендуется начинать конечные точки вашего проекта, что должны

улучшенные функциональные возможности для новых клиентов. По  мере
дальнейшего развития кода можете удалить конечные точки v1 в любое вре-

@app.post("/api/v1/names", status_code=status.HTTP_201_CREATED)
async def create_name(name: dict):
    new_name = name["name"]
    names.append(new_name)
    return {"message": "Name added successfully"}
В предыдущей конечной точке POST рекомендуется при успешном вызове
возвращать код состояния HTTP 201, указывающий, что API создал новые дан-
ные. Код FastAPI работает совсем не так, как Flask. Вместо отдельных объектов
запроса и ответа все неявно. Если вы ожидаете, что JSON будет отправлен в ка-
