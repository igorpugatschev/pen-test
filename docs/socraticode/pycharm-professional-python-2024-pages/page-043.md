def print_hi(name):
    print(f’Hi, {name}’)
    for x in range(25):
        print(str(x))
        if x == 12:
            return
            print(«You’ll never make it here»)
    if __name__ == ‘__main__’:
        print_hi(‘PyCharm’)
Функция print_hi	 запускается достаточно безобидно, выдавая на консоль
все, что передается в функцию в аргументе name.	После этого мы создаем цикл,
который будет выполняться 25 раз. При каждом запуске цикла мы выводим x,
который содержит текущую итерацию. Когда переменная-счетчик x достига-
ет 12, цикл завершается через функцию return,	которая, как назло, находится
в строке 12. Уверяю вас, это чистое совпадение. Поскольку цикл возвращается
в строке 12, код в строке 13 никогда не будет достигнут:
Рис. 1.5.	PyCharm выделит многие распространенные ошибки кодирования, подобные этой.
Код в строке 13 недоступен, на что указывает наведение курсора мыши на выделенный код
PyCharm также позволяет вам перемещаться между файлами в  сложном

хотите реализовать, и это позволяет быстрее завершить свой код с меньшим
количеством ошибок.
