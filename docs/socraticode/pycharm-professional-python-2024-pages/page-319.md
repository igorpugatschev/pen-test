Подводя итог, если мы передадим массив с  нулевыми элементами, Jinja2
отобразит строку, которая у нас была раньше, где указано, что данных нет. Если
в массиве есть данные, Jinja2 перебирает массив и генерирует строку таблицы
для каждой строки данных.
