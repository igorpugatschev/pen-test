Quick Documentation

те просто навести указатель мыши на вызов функции и немного подождать.

ментацией, похожее на рис. 4.33:
Рис. 4.33.	Quick Documentation показывает документацию для выбранной функции
Более того, вы также можете просмотреть документацию для своих соб-
ственных функций, методов, классов и т. д., используя то же действие. Процесс
индексирования PyCharm находит и генерирует эту информацию при откры-
тии проекта.
