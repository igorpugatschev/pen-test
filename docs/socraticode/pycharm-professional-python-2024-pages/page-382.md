Рис. 10.16.	Т еперь мы можем без особых усилий добавлять, редактировать и удалять авторов
У нас есть модель Author; давайте добавим Book. Этот немного причудливее.
Помните, что между Книгой и Автором существует связь. Каждый Автор может
быть связан со многими Книгами, или, наоборот, многие Книги связаны с од-
ним Автором.
Поскольку это так, нам нужно, чтобы интерфейс администратора не только
отражал эти отношения, но и обеспечивал их соблюдение на уровне пользова-
тельского интерфейса. Вы можете просто импортировать модель книги и ожи-
дать, что она будет работать идеально.
Вернитесь к файлу admin.py и добавьте этот код:
from django.contrib import admin
# Register your models here.
from .models import Author, Book
class BookInLine(admin.TabularInline):
    model = Book
    extra = 1
    fieldsets = [
        (None, {'fields': ['title']}),
        ('Date information', {'fields': ['pub_date']})
]
