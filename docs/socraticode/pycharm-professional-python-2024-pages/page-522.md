Преобразование числовых данных в реальные числа
Наша следующая ячейка содержит несколько строк кода, предназначенных для
преобразования числовых значений в  числовые типы. Помните, что все по-
ступает в виде текста и обрабатывается как строка, пока вы не укажете pandas
иное. Вот код ячейки:
#%% Change numeric data into appropriate format
# force some columns to have numeric data type
user_df['BirthYear'] = pd.to_numeric(user_df['BirthYear'],errors='coerce')

ce')
