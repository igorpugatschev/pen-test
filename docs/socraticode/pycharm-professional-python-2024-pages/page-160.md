def computer_science_average(grades: dict) -> float:
    raw_total = 0
    for grade in grades.values():
        raw_total += grade
    average = (raw_total / len(grades))
    return average
Сигнатура нашего метода дает много полезных подсказок. У нас есть описа-
тельное имя функции. Функция принимает один параметр, и наша подсказка
сообщает нам, что мы ожидаем словарь. Ожидается, что функция вернет число
с плавающей запятой.
