Просмотр различий
Вам не нужен конфликт, чтобы использовать окно сравнения, которое мы только
что видели. Окно различий – это окно, в котором рядом отображаются две (или
более) версии кода. Вы можете различать ветки или версии. Допустим, я быстро
вношу изменения в наш объединенный код, добавив следующую строку:
text = "I'm adding this line"
Я также удаляю строку 2, которая гласит:
text = "I'm adding this line"
Мой код теперь совсем другой. Если я хочу сравнить свой новый код с по-
следним кодом ветки, я  могу кликнуть правой кнопкой мыши вкладку main.
