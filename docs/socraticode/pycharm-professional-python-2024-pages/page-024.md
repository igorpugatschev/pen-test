В этой книге используется ряд текстовых соглашений.
Code in text : указывает кодовые слова в тексте, имена таблиц базы данных,
имена папок, имена файлов, расширения файлов, имена путей, фиктивные URL-
адреса, пользовательский ввод и дескрипторы Twitter. Вот пример: «Мы вычис-
ляем корреляционную матрицу этого набора данных с помощью метода corr()».
Блок кода задается следующим образом:
# Compute and show correlation matrix
corr_mat = df.corr()
plt.matshow(corr_mat)
plt.show()
