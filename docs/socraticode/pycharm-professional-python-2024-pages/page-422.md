Чтобы добавить ключ, нажмите кнопку +,	показанную стрелкой, затем клик-

придерживаетесь автоинкрементного целого числа для своего ключа, созда-
ние составного первичного ключа не требуется. Я считаю, что код с составным
ключом издает некий запах, не будем уточнять.
