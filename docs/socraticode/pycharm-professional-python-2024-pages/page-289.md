Другие фреймворки для фронтенда
PyCharm поддерживает несколько других современных интерфейсных фрейм-
ворков.
	 Angular	похож на React в том, что он использует компоненты, управля-
емые конечным автоматом. Самым большим отличием, помимо печаль-
но известного отсутствия обратной совместимости основных выпусков,
является двунаправленная связь между компонентами. В React свойства
детализируются сверху вниз. В Angular связь между компонентами идет
в обоих направлениях. Это может затруднить отладку ваших приложений.
	 React	 Native  – это ответвление React, предназначенное для создания

чает вариант React Native для создания пользовательских интерфейсов
Windows для настольных приложений.
