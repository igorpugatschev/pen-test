Отладка JavaScript на стороне клиента
Вы можете отладить JavaScript, который работает в вашем браузере, настроив
Google Chrome в качестве браузера по умолчанию. В Chrome встроен очень хо-
роший сервер удаленной отладки. PyCharm может подключиться к нему и ото-
бразить отладочную информацию непосредственно в пользовательском интер-
фейсе PyCharm, так же как она выглядела бы при отладке кода Python в главе 6.
Откройте файл index.js и установите точку останова в нашей функции хенд-
лера кликов в строке 7, как показано на рис. 7.14:
