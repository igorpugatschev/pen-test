Рис. 3.24.	Окно терминала, которое я использовал для
создания проекта Python полностью вне PyCharm
Процесс, которому я следовал, четко описан здесь.
1.  В новой папке проекта под названием manually-created я  создал новую
виртуальную среду с помощью команды python3 -m venv venv.
2.  Я активировал виртуальную среду с помощью команды source venv/bin/
activate. В данном случае я работаю в Linux. Эта же команда будет рабо-
тать на Mac. Если бы я использовал Windows, это было бы .\venv\Scripts\
activate.
3.  Далее я  установил сторонний модуль под названием tqdm. Вы  можете
узнать больше на https://pypi.org/project/tqdm/. Краткая версия этого мо-
дуля используется для легкого форматирования вывода программы на
терминале и включения красивого индикатора выполнения. Вы можете
увидеть блочный индикатор выполнения чуть ниже на рис.  3.24 после
запуска программы. Я забегаю вперед.
4.  Я использовал nano, чтобы добавить код в новый файл с именем main.py.
Я покажу вам содержимое чуть позже, но все, что я сделал, – это скопи-
ровал и вставил пример из документации tqdm на страницу https://pypi.
org, ссылку на которую я  давал ранее. Если вам интересно, что делает
ключ -l, он отображает номера строк в  редакторе nano, что делает nano
быстрым и простым в использовании редактором кода.
5.  Я запустил программу с помощью команды python main.py.
6.  Убедившись, что все работает, я создал файл requirements.txt, чтобы до-
кументировать зависимость моей программы от модуля tqdm. Команда
