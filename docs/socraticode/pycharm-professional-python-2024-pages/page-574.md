Рис. 15.22.	Используйте сеанс терминала для создания папки
Используйте показанные команды, чтобы создать новую папку. У меня уже
была папка PyCharmProjects	на удаленном компьютере в моей домашней папке.
Это связано с тем, что PyCharm фактически установлен на удаленном компью-
тере, поскольку это мой компьютер для ежедневного использования. Вы може-
те создать там любую подходящую вам папку. Можете выйти из сеанса терми-
нала, набрав команду exit.
