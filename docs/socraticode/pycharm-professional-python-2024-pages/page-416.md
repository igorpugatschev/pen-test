данных, PyCharm поддерживает параметры конфигурации SSL и SSH. Смотри-
те рис. 11.18, где показаны варианты настройки безопасности для ваших ис -
точников данных.

в IDE, поскольку они понадобятся вам для провайдеров облачных услуг, таких
как Microsoft Azure.
