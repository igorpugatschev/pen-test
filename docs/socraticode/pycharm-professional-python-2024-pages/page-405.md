Остановка и запуск контейнера
Когда вы будете готовы уйти с работы домой, можете остановить контейнер:
docker stop pycharm-mysql
Это останавливает контейнер. Вы можете проверить это с помощью той же
команды docker ps -a , которую мы использовали для подтверждения измене-
ния статуса с Up на Stopped. Завтра утром, когда вернетесь, напишите следую-
щее:
docker start pycharm-mysql
Это запустит процесс, и вы сможете продолжить с того места, на котором
остановились.
