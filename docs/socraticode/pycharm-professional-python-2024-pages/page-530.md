Эта первая строка пытается заставить значения в  столбце Date быть дата-
ми. Если принуждение не сработает, мы увидим NaT (Not a Time, «невремя»),
что разочаровывает, поскольку здесь нет никакой шутки о еде. Далее выпол-
ним еще несколько принудительных изменений в полях Hold time, Latency time
и Flight time:
df['Date'] = pd.to_datetime(df['Date'], errors='coerce',
format='%y%M%d').dt.date
# converting time data to numeric
for column in ['Hold time', 'Latency time', 'Flight time']:
df[column] = pd.to_numeric(df[column], errors='coerce')
Любые наблюдения, в  которых отсутствуют временные данные, должны
быть исключены:
df = df.dropna(axis=0)
