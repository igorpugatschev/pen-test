Установка диалекта SQL (это важно)
Поскольку PyCharm поддерживает десятки различных баз данных, каждая из
которых имеет свой собственный диалект SQL, вполне понятно, что может
потребоваться указать PyCharm, какой диалект SQL вы собираетесь исполь-
зовать. Вам не составит труда запомнить это, потому что PyCharm будет бес -
покоить вас, пока вы не заполните эту настройку.
