Рис. 5.11.	Настройки моего удаленного доступа
Обратите внимание, что установлен только самый минимум. Нет файла
.gitignore ,	нет файла README и т. д. Я собираюсь добавить все это в PyCharm.
Когда я нажимаю кнопку Create	 repository, 	GitHub генерирует URL-адрес,
который мне нужен для добавления удаленного устройства. Я указал на это
на рис. 5.12.
Затем вернитесь к PyCharm и найдите меню git	в главном меню. Помните,
минуту назад в меню было написано VCS,	потому что мы не определили репо-
зиторий, а теперь написано git.
В меню git	вы найдете опцию Manage	Remotes. Нажмите на нее, и вы уви-
дите модальное диалоговое окно, показанное на рис. 5.13, которое позволяет
вам добавить только что созданный вами удаленный доступ на GitHub.
