Один агрегат = один репозиторий
Итак, мы определили некие сущности как агрегаты. Самое время вспомнить
о правиле: эти сущности — единственные, доступ к которым публичный.
Другими словами, единственные репозитории, к которым у нас есть доступ,
должны быть теми, которые возвращают агрегаты.
Помните, что агрегаты должны быть единственным путем в вашу модель
предметной области? Чтобы добиться этого, руководствуйтесь правилом:
репозитории должны возвращать только агрегаты. Не нарушайте его!
