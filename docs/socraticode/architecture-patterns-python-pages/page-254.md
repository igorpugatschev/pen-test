Альтернатива с использованием классов
Замыкания и частично примененные функции — не проблема для тех, кто
знаком с функциональным программированием. Если это не про вас, то
есть неплохой альтернативный вариант. Но для этого потребуется пере-
писать все функции-обработчики в виде классов.
