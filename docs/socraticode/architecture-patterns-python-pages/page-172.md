Вариант 2: сервисный слой инициирует собственные
события
Еще один вариант — сделать так, чтобы сервисный слой непосредственно
отвечал за создание и инициирование событий, а не за получение их из
модели предметной области, которая их инициирует.
Сервисный слой вызывает messagebus.handle напрямую (src/allocation/service_layer/services.py)
