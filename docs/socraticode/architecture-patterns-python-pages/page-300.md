Т есты
Т есты хранятся вместе со всем остальным, как показано здесь:
Дерево папок с тестами
└── tests
 ├── conftest.py
 ├── e2e
 │ └── test_api.py
 ├── integration
 │ ├── test_orm.py
 │ └── test_repository.py
 ├── pytest.ini
 └── unit
 ├── test_allocate.py
 ├── test_batches.py
 └── test_services.py
Ничего выдающегося здесь нет, просто разделены некоторые типы тестов,
которые вы, может быть, захотите выполнять отдельно, и несколько файлов
для совместных фикстур, конфигураций и пр.
В тестовых папках нет папки src или файла setup.py, потому что обычно
делать тесты пригодными для установки через pip не приходилось. Но при
трудностях с путями импорта такой способ может помочь.
