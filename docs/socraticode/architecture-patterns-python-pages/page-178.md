События помогают придерживаться принципа единственной обязанности
Код запутывается, когда в одном месте смешивается несколько обязанностей.
События помогают поддерживать порядок, отделяя первичные варианты
использования от вторичных. Мы также используем события для обмена
данными между агрегатами, благодаря чему не нужно выполнять длительные
транзакции, которые блокируют нескольких таблиц.
Шина сообщений направляет сообщения обработчикам
Можно рассматривать шину сообщений как словарь, который попарно сопо-
ставляет события с их потребителями. Она ничего не «знает» о сути событий;
это просто элемент немой инфраструктуры для передачи сообщений по всей
системе.

после того, как вы зафиксируете свой UoW .
