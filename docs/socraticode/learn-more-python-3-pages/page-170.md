После того как вы определили все символы в примере кода выше, вам нужно
их назвать. Вы не можете просто ссылаться на них посредством соответствую­
щих регулярных выражений, поскольку такой поиск неэффективен и запутан.
Позже вы узнаете, что предоставление каждому символу собственного имени
(или числа) упрощает анализ, но пока давайте разработаем некоторые име­
на для этих шаблонов регулярных выражений. Можно сказать, что def - это
просто DEF, тогда символы () +:, могут быть LPAREN RPAREN PLUS COLON
СОММА (левая скобка, правая скобка, плюс, двоеточие, запятая). После этого
я могу назвать регулярное выражение для слов вроде hello и print про­
сто NAME (имя). Таким образом я придумываю способ преобразовывать поток
вводимого кем-то «сырого» текста в поток определенных токенов для исполь­
зования их на более поздних этапах.
Кроме того, Python каверзен, ведь ему нужно регулярное выражение для про­
бельных символов, чтобы обрабатывать отступы блоков кода. Пока давайте
просто глупо используем A\s+ и притворимся, что это также предусматрива­
ет, сколько пробелов было в начале строки.
В конце концов, у вас будет набор регулярных выражений, которые могут об­
