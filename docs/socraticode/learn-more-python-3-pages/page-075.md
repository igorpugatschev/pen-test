Описание
При работе со многими структурами данных в языке Python и многих других
объектно-ориентированных языках программирования, вы должны пони­
мать три основные концепции.
1. «Узел». Обычно это контейнер или ячейка памяти для структуры дан­
ных. Ваши значения отправляются сюда.
2. «Ребро», но мы будем использовать термин «указатель» или «ссыл­
ка». Указывает на другие узлы. Располагается внутри каждого узла,
обычно как переменная экземпляра.
3. «Контроллер». Это некий класс, знающий, как использовать указате­
ли в узле, чтобы корректно структурировать данные.
