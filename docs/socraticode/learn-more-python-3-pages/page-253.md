252 ЛЕГКИЙ СПОСОБ ВЫУЧИТЬ PYTHON 3 ЕЩЕ ГЛУБЖЕ
Просто старайтесь быть настолько педантичными, насколько возможно, а
также используйте автоматическое тестирование, чтобы убедиться, что ваша
и исходная команда sed работают одинаково.
Наконец, при работе над sed вы найдете в модуле необходимые вам компо­
ненты. Вам нужно будет внести изменения в модуль, заставить их работать
в sed, а затем вернуться к ed и заставить их работать там. Этот процесс ме­
тания между тремя проектами будет нелегким, поэтому я предлагаю вам
придерживаться 45-минутного подхода, чтобы не выдохнуться из-за пере­
ключений контекста.
