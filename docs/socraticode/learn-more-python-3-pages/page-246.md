# Легкий способ выучить Python 3 еще глубже — страница 246

ИНСТРУМЕНТ BLOG 245
рактические задания
1. Статические файлы на вашем собственном сервере - это прекрасно,
но разве не было бы лучше, если бы blog работал с облаком Ama ­
zon S3? Есть проект под названием Boto3 (aws.amazon.com/sdk-for-
python/), в котором найдется все необходимое для реализации.
2. Напишите команду blog serve, которая использует класс Sim-
pleHTTPServer, чтобы просто разместить блог на сервере напря­
мую и не генерировать его отдельно.
