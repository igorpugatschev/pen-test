отличную от двусвязного списка. Код в Википедии предполагает некий вид
структуры массива или списка. Строки вроде
if A[i—1] > A[i] then
вы должны перевести на язык Python с использованием двусвязного списка:
if node.prev.value > node.value:
Мы не можем просто получить доступ к двусвязному списку, так что нужно
конвертировать эти операции с индексом массива в .next и .prev. Кроме
того, нужно следить, чтобы при прохождении атрибуты next или prev были
None. Такие превращения предполагают большой объем работы с перево­
дом, изучением и угадыванием семантики читаемого псевдокода.
