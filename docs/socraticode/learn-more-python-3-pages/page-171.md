A\s + INDENT
Задача лексического анализатора состоит в том, чтобы брать эти регулярные
выражения и использовать их для разбиения входного текста на поток иден­
тифицированных символов. Если я сделаю это с примером кода, получится
следующее:
DEF NAME(hello) LPAREN NAME (х) COMMA NAME (у) RPAREN COLON
INDENT(4) NAME(print) LPAREN NAME(x) PLUS NAME(y) RPAREN
NAME(hello) RPAREN INTEGER(10) COMMA INTEGER(20) RPAREN
Изучите это преобразование, сопоставляя каждую строку этого вывода лекси­
ческого анализатора и сравнивая вывод с приведенным выше кодом Python,
используя регулярные выражения в таблице. Вы увидите, что все сводится
к тому, чтобы взять входной текст (ввод) и поставить в соответствие каждое ре­
гулярное выражение и имя токена, после чего осуществить сохранение всей
необходимой информации, например hello или числа 10.
