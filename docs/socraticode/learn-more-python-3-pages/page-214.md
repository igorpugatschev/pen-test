Создание в SQL
В
 акрониме CRUD буква С означает create (создать), но это не просто соз­
дание таблиц. Здесь также имеется в виду вставка данных в таблицы и
использование таблиц и вставок для связывания (компоновки) таблиц. По­
скольку нам нужны таблицы и определенные данные для остальной части

нять базовые операции создания в SQL.
Создание таблиц
Во вступлении в упражнении 38 я упомянул, что вы можете выполнять опера­
ции CRUD с данными внутри таблиц. Как нам создать таблицу? Путем выпол­
нения CRUD со схемой базы данных, и первая инструкция SQL, которую мы
рассмотрим, это CREATE:
exl.sql
1 CREATE TABLE person (
2 id INTEGER PRIMARY KEY,
3 first_name TEXT,
4 last_name TEXT,
5 age INTEGER
6 ) ;
Можно вместить все это в одну строку, но я разделил ее на несколько, потому
что хочу рассмотреть каждую из них.

Начало CREATE table (создать таблицу), дающее нам имя таблицы -
person. Далее вы помещаете в скобки нужные поля.
