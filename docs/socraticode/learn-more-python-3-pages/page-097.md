Сортировка слиянием
Я пока не совсем готов оставлять вас в одиночестве. Вы должны будете повто­
рить эту процедуру для сортировки слиянием, но сейчас я хочу, чтобы вы по­
пытались решить алгоритм, основываясь только на псевдокоде со страницы
в Википедии (en.wikipedia.org/wiki/Merge_sort), прежде чем посмотреть,
как это сделал я. Существует несколько возможных реализаций, но я исполь­
зовал вариант «сверху вниз»:
function merge_sort(list m)
if length of m < 1 then
return m
var left := empty list
var right := empty list
for each x with index i in m do
if i < (length of m) /2 then
add x to left
else
add x to right
