Грамматика формы Бэкуса - Наура
Трудновато пытаться написать парсер МРС с нуля без какой-либо специ­
фикации грамматики. Помните, как я попросил вас преобразовать одно
регулярное выражение в конечный автомат? Это было трудно, правда?
Для этого требовалось гораздо больше кода, чем несколько символов ре­
гулярного выражения. Когда в этом упражнении вы станете писать синтак­
сический анализатор МРС, вы сделаете аналогичную вещь, так что будет
удобно располагать языком, являющимся «регулярным выражением для
грамматик».
Наиболее распространенным «регулярным выражением для грамматик» яв­
ляется форма Бэкуса - Наура (БНФ), названная в честь создателей — ученых
Джона Бэкуса и Петера Наура. БНФ описывает требуемые токены и то, как эти
токены повторяются при формировании грамматики языка. БНФ использует
те же символы, что и регулярные выражения, поэтому *, + и? имеют сходные
значения.
Для этого упражнения я собираюсь использовать синтаксис расширен­
ной БНФ (tools.ietf.org/html/rfc5234), чтобы определить грамматику для
фрагмента Puny Python. Операторы РБНФ в основном такие же, как у регу­
лярных выражений, за тем исключением, что по какой-то странной причи­
не они указывают повторение перед повторяющимся элементом, а не после.
В остальном прочтите спецификацию и попытайтесь выяснить, что означает
следующее:
root = *(funccal / funcdef)
funcdef = DEF name LPAREN params RPAREN COLON body
funccall = name LPAREN params RPAREN
params = expression *(COMMA expression)
expression = name / plus / integer
plus = expression PLUS expression
PLUS = ”+"
LPAREN = "("
RPAREN = ”)”
COLON = ”:"
COMMA = ”,"
DEF = "def"
Давайте взглянем только на строку funcdef и по соответствующим частям
сравним ее с function_definition из указанного выше кода Python.
